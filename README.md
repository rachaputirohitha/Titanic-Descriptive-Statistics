# Titanic Dataset – Descriptive Statistics

## Project Overview

This project performs descriptive statistical analysis on the Titanic dataset using Microsoft Excel and Python with Pandas in Google Colab.

The analysis focuses on four numerical variables:

- Age
- Fare
- SibSp
- Parch

## Objectives

- Calculate Mean
- Calculate Median
- Identify Mode
- Calculate Standard Deviation
- Calculate 25th, 50th and 75th Percentiles
- Calculate Interquartile Range (IQR)
- Understand the distribution and variation of numerical variables

## Tools Used

- Microsoft Excel
- Google Colab
- Python
- Pandas

## Dataset

The Titanic dataset contains 891 passenger records along with information such as survival status, passenger class, sex, age, fare and family-related variables.

## Key Observations

- The average passenger age is approximately 29.70 years.
- The median passenger age is 28 years.
- Fare has a higher mean than median, showing a noticeable spread in fare values.
- SibSp and Parch have a median and mode of 0.
- Fare has the highest standard deviation among the selected variables.
- IQR was calculated as Q3 - Q1.

## Conclusion

The Titanic dataset was successfully analyzed using Excel and Python/Pandas. Descriptive statistics were calculated to understand the central tendency, variation and distribution of the selected numerical variables.
